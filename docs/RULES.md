# 规则范围

这是按项目需求重构的标准规则版本，不是参考项目全量复刻。无军争牌、国战、排位 3v3、双将或全量武将扩展。

## 玩家和身份

| 人数 | 主公 | 忠臣 | 反贼 | 内奸 |
| ---- | ---- | ---- | ---- | ---- |
| 2    | 1    | 0    | 1    | 0    |
| 3    | 1    | 0    | 1    | 1    |
| 4    | 1    | 1    | 1    | 1    |
| 5    | 1    | 1    | 2    | 1    |
| 6    | 1    | 1    | 3    | 1    |
| 7    | 1    | 2    | 3    | 1    |
| 8    | 1    | 2    | 4    | 1    |

2 人为简化主公对反贼对决，3 人为缩小身份局，沿用参考项目的小人数设计，不是官方竞技 1v1 / 3v3 规则。4–8 人使用标准身份配比。多局比赛默认循环轮换 Agent 座位；全部身份随机分配，主公可位于任意座位，并先开始首个回合。重新轮到主公时进入下一轮。主公公开，其余身份在本人视角和死亡后可见。5 人以上主公体力上限 +1，与座位无关。

创建界面显示首局随机身份，可手动交换。手动调整切换为固定身份模式，后续多局身份始终跟随玩家；每局随机模式只沿用首局预览，之后按各局种子重新分配。身份总人数与配比由服务端校验。已有牌局的身份保持原记录。

主忠消灭全部反贼与内奸即胜。主公死亡时，只有内奸独自存活才判内奸获胜；否则反贼胜，包括仍有忠臣与内奸存活的情况。达到设置的决策上限判平局，并如实记录原因，不用体力分数伪造胜者。

## 卡牌与回合

108 张标准包（含 4 张 EX），每个花色 27 张。30 杀、15 闪、8 桃、4 无懈可击。牌面花色、点数是固定公开数据，不使用随机配花色的近似牌堆。

准备 → 判定 → 摸牌 → 出牌 → 弃牌 → 结束。初始每人四张，正常摸牌两张。弃牌至当前体力值（最低为 0）。出牌阶段通常限一张杀。默认无酒、属性杀、铁索连环、火攻、兵粮寸断。

弃牌阶段一次选择并弃置全部超额手牌，仅产生一次接受决策及至多一次行动后 RSI。引擎拒绝数量错误、重复牌、装备牌或其他玩家手牌。雌雄双股剑等其他响应窗口仍按其规则单独处理。

攻击距离按存活座位的最短环距计算，叠加进攻马、防御马、马术，最低为 1。武器提供攻击范围。转化 / 弃掉装备时不会继续使用该装备提供的范围或次数效果。

支持无中生有、过河拆桥、顺手牵羊、决斗、南蛮入侵、万箭齐发、桃园结义、五谷丰登、借刀杀人、无懈可击、乐不思蜀、闪电。无懈按每名目标独立结算，并支持反无懈链；本项目为稳定的 Agent 调度，将同时响应机会序列化为从当前回合角色起按座位轮流询问。

延时锦囊在目标判定阶段询问无懈。乐不思蜀非红桃跳过出牌；闪电黑桃 2–9 造成 3 点无来源伤害，否则按座位传给判定区没有闪电的存活角色。判定区按后进入者先结算。

顺手牵羊 / 过河拆桥可选择手牌、装备、判定区；对手手牌只给出位置，不泄露真实牌 ID。濒死时按当前回合起的座位顺序询问桃，可以连续补足负体力。死亡清理区域，击杀反贼摸三张；主公杀忠臣弃置全部手牌与装备。

## 基础武将

为避免用不完整技能冒充全量武将，当前仅开放 8 名角色：

| 武将   | 技能                                             |
| ------ | ------------------------------------------------ |
| 张飞   | 咆哮                                             |
| 关羽   | 武圣（红色手牌或装备转杀）                       |
| 赵云   | 龙胆（手牌杀闪互换）                             |
| 马超   | 马术、铁骑（红色判定不能以闪响应，仍检查仁王盾） |
| 黄月英 | 集智、奇才                                       |
| 许褚   | 裸衣                                             |
| 张辽   | 突袭                                             |
| 吕布   | 无双（双闪与决斗双杀）                           |

创建比赛时直接选择武将，不提供选将草稿流程。允许重复武将，方便同条件模型实验。

## 规则验证策略

规则测试覆盖卡牌守恒、转化牌距离、杀次数、双闪、决斗、无懈链、延时判定、负体力救援、死亡奖惩、装备效果、个人视角隐私。端到端仿真覆盖 2–8 人与多个种子，每一个动作之后检查全部 108 张牌只属于一个区域。引擎使用串行任务队列，响应不能与下一动作交错。
