# 页面主题与设计参考

[文档导航](README.md) · [观战指南](ARENA_UI.md) · [截图与来源](MEDIA.md)

大厅与每款游戏具有独立的页面主题。主题覆盖背景、导航、字体、表单、弹窗、侧栏和场地，而不是仅设置棋盘强调色。三国杀保留原有墨绿金色样式。

## 主题方向

| 页面     | 色彩与材质                                         | 字体与组件                                   |
| -------- | -------------------------------------------------- | -------------------------------------------- |
| 游戏大厅 | 蓝白、淡蓝灰底，白色搜索框；各游戏卡片预览自身主题 | 无衬线大标题、圆角目录卡片、几何游戏符号组合 |
| 三国杀   | 墨绿牌桌、金色强调、暖色手牌                       | 原有宋体标题、武将与手牌布局                 |
| 狼人杀   | 午夜蓝、月光银紫、暗红私聊提示；星点与月轮         | 衬线标题、拱形角色席位、独立夜色侧栏与弹窗   |
| 国际象棋 | 中性灰白、石板灰棋格、黑白棋子                     | 无衬线标题、紧凑直角组件、等宽着法信息       |
| 中国象棋 | 宣纸米白、朱砂红、浅木色棋盘                       | 宋体、双线边框、印章、纸面纹理               |

浅色主题使用深色正文、深色按钮与浅色按钮文字；狼人杀使用浅色正文。状态、行动与身份仍通过文字和形状表示，不仅依赖颜色。棋盘翻转、坐标、落子与将军标识保持原有功能。

## 参考来源与采用范围

- [Board Game Arena](https://en.boardgamearena.com/welcome)：参考游戏目录的组织方式、多游戏入口与明确的进入路径。大厅的蓝白配色、几何图形和卡片样式为本项目设计。
- [Lichess](https://lichess.org/) 与 [Chess.com 对局页面](https://www.chess.com/play/online/new)：参考以棋盘和对局控制为中心的功能组织。国际象棋采用本项目自己的中性棋室主题。
- [Blood on the Clocktower](https://bloodontheclocktower.com/)：参考社会推理游戏的角色与悬疑叙事方向。狼人杀使用独立绘制的月亮符号、星点和角色框。
- 中国象棋采用纸张、木质棋盘与朱砂印章的视觉语言；三国杀沿用项目已有主题。

以上是设计方向与信息组织参考，不是网站复刻。未引入这些网站的商标、图片、字体文件或代码。页面图形与纹理由本地 CSS 和 SVG 绘制，实际效果以项目浏览器截图和交互回归为准。

## 代码组织

- `web/themes.css`：整页主题变量、公共控件主题绑定，以及三款新游戏的字体、边框、材质与棋盘差异。
- `web/lobby.css`：大厅布局与四种游戏卡片的视觉预览。
- `web/game-presentation.ts`：名称、文案、游戏强调色。
- `web/multigame.css`：共用观战布局，颜色通过 `--theme-*` 变量获取；保留默认值以兼容独立渲染。
- `web/arena-design.css`：原有壳层与三国杀界面修饰。
- `web/main.tsx`：根据当前页面设置 `data-theme` 与主题类。大厅始终是 `lobby`，不继承最近访问游戏的主题。

核心变量包含 `--theme-page`、`--theme-surface`、`--theme-panel`、`--theme-control`、`--theme-ink`、`--theme-muted`、`--theme-line`、`--theme-accent`、`--theme-on-accent`、`--theme-heading` 与 `--stage-background`。新增游戏应提供自身变量和所需的场地样式，不应修改全局 `:root` 来改变所有游戏。

玩家库和规则接入页继续使用原有工具页面样式。整页主题仅作用于大厅及对应游戏，避免改变三国杀卡牌、动画和既有档案组件。

## 验证

`tests/e2e/themes.spec.ts` 检查三款新游戏的创建弹窗、输入框、主要按钮及回到实时控件的文字对比度（至少 4.5:1），并检查移动端宽度和返回大厅后的主题恢复。现有浏览器回归继续覆盖两种语言、创建、聊天、经验、暂停、回放、翻转、历史导航和三国杀流程。
