# 国际象棋

[English](chess.en.md) · [游戏目录](README.md)

规则版本：`standard-v1`。两人，白方先行；支持中英文界面、规则和 Agent / RSI 提示词。多局默认轮换座位，使同一玩家交换黑白。

## 规则与动作

使用固定版本 `chess.js 1.4.0` 生成和校验合法走法，支持将军约束、王车易位、吃过路兵，以及升后、车、象、马。棋盘与走法信息完全公开。普通走子 ID 为 UCI，例如 `e2e4`、`e7e8q`；界面同时显示 SAN 记谱。

- 将死获胜；困王（无合法走法但未被将军）和棋。
- 常见子力不足局面由 chess.js 判和，例如单王、王加单象/单马对单王、同色格象的特定情况。
- 三次重复、五十回合规则需选择 `claim_draw`；若下一步将满足条件，可使用 `claim:<UCI>` 声明走法并申请和棋，棋盘不实际执行该声明步。
- 五次重复、七十五回合自动和棋；最后一步将死优先于七十五回合判和。
- `resign` 认输。平台决策上限另作实验性平局，原因与规则和棋分开记录。

无棋钟、线下触子落子处罚或裁判申诉程序。子力判和采用库的 material 检测，未穷举所有罕见的死局证明。可用 `offer:<UCI>` 走子并提和，对手可通过 `accept_draw` 接受或用正常走子拒绝；提和状态随检查点保存。

## 交流、经验与恢复

每一步可以附带可选公开 `speech`。发言在走子前记录，不作为规则命令；棋手只可选择引擎列出的动作。单独的策略理由不公开到聊天室。

即时 RSI 在走子提交后执行，赛后 RSI 在终局后执行；经验按玩家和 `chess` 隔离。中英文棋局共享同类型经验，新的反思按本场语言生成。

检查点保存初始 FEN、完整 UCI 走子列表、当前 FEN 及重复局面计数。恢复重建完整走子历史并核对当前 FEN，避免只保存 FEN 而丢失三次重复判定。
